🎙 LIVETEXT IRL

Tal blir text, direkt i din webbläsare

💡 Vad appen gör:

  • Live-transkribering i realtid – när någon talar, visas texten direkt på skärmen.
  • Ingen installation krävs – körs direkt i Chrome (fungerar även i Edge, Safari och på iPhone).
  • Allt sker lokalt – ingen server används, inget ljud skickas iväg.

🔧 Funktioner:

  • Taligenkänning via Web Speech API – omvandlar tal till text automatiskt.
  • Stöd för flera språk – välj igenkänningsspråk som passar ditt event.
  • Anpassningsbar textvisning – ändra textstorlek och färg efter behov.
  • Lägg till egna ord och namn – förbättra igenkänningen med t.ex. talarnamn eller facktermer.
  • Helskärmsläge med teleprompterkänsla – för tydlig visning vid livevisning eller scen.
  • Spara som undertextfil (.srt) – ladda ner transkriptionen med tidskoder för användning i videoredigering.
  • Dela enkelt med andra – generera en länk eller QR-kod för snabb åtkomst.

🛠 Hur det fungerar:

  • Appen startas med ett klick – ingen inloggning eller registrering behövs.
  • Mikrofonen används för att lyssna på talet.
  • Texten visas direkt i ett tydligt fönster och sparas i bakgrunden.
  • När du är klar kan du ladda ner allt som en färdig undertextfil (.srt).

LIVETEXT IRL har skapats av Joakim Hesselman för att användas i samband med Samhalls årsstämma i maj 2025.
